# Sourced catalog drafts

Observed 2026-10-27. These are starting points for user review, not seeded entitlements and not a complete catalog. The source observation date is never substituted for the issuer's effective date. The user must verify identity, applicable terms, effective dates, eligibility and enrollment. All nine initial cards are unverified and have zero automatic benefit rules.
